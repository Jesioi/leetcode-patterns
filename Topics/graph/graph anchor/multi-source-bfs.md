# Multi-source BFS/ BFS layering

Core Pattern:
level-order graph expansion

Core Insight:
BFS expands shortest distance layer by layer

Core Components:

- queue
- level traversal
- multi-source initialization

Typical Signals:

- shortest steps
- minimum moves
- spread over time
- nearest distance

Common Bugs:

- forgetting visited
- incorrect level increment
- duplicate enqueue

Representative Problems:

- Rotting Oranges
- Walls and Gates
- 01 Matrix
