# BST Invariant

Core Invariant:
inorder traversal of BST is sorted

Rule:
left < root < right

Key Insight:
BST problems often reduce to:
"inorder sorted order"

Signals:

- validate BST
- kth smallest
- inorder traversal
- successor/predecessor

Representative Problems:

- Validate Binary Search Tree
- Kth Smallest Element in BST
