3. In-place Reversal

7. Deep Copy Linked Structure

---

## 1. Pointer Traversal

basic linear traversal

Core Idea:

move pointer through linked structure

Representative:

- Linked List Cycle
- Find Middle of Linked List
- Remove Nth Node From End

---

## 2. Fast & Slow Pointers

two pointers moving at different speeds

Core Idea:

relative speed creates meeting point / midpoint

Representative:

- Linked List Cycle
- Find Duplicate Number
- Reorder List

---

## 3. In-place Reversal

reverse pointers during traversal

Core Idea:

store next
reverse current link
move forward

Representative:

- Reverse Linked List
- Reverse Linked List II
- Reverse Nodes in K Group

---

## 4. Dummy Node Manipulation

use dummy node to simplify edge cases

Core Idea:

dummy stabilizes head operations

Representative:

- Merge Two Sorted Lists
- Remove Nth Node From End
- Partition List

---

## 5. Merge Pattern

merge multiple sorted linked structures

Core Idea:

compare nodes
attach smaller node
advance pointer

Representative:

- Merge Two Sorted Lists
- Merge K Sorted Lists

---

## 6. K-group / Segment Manipulation

reverse or manipulate subranges

Core Idea:

identify segment boundaries
reconnect modified segments

Representative:

- Reverse Nodes in K Group
- Reorder List

---

## 7. Deep Copy Linked Structure

copy node relationships using hashmap

Core Idea:

old node maps to new node

Representative:

- Copy List With Random Pointer
- Clone Graph
